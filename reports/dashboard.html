ViGoEmotions Ekman-7 — Model Analysis Dashboard

Vietnamese fine-grained emotion detection · 7 Ekman classes · test set 2,067 samples

Label Mapping — 28 GoEmotions → 7 Ekman Groups (training set)
Each source node is one of the 28 original GoEmotions labels. Node width is proportional to frequency in the training set. The mapping shows that joy consolidates 12 labels (the largest group), while disgust and neutral each retain only their original label — no merging occurred.
Per-Label F1 — Radar Comparison
CafeBERT leads on all 7 emotions. All three models struggle most on neutral (F1 ≤ 0.46) and disgust (F1 ≤ 0.54), suggesting class imbalance and semantic ambiguity rather than model capacity issues.
Confusion Heatmap — Predicted Label Rate Given True Label
Row = true emotion. Each cell = fraction of true-label samples that were also predicted as the column emotion. Diagonal = recall per class. High off-diagonal values reveal systematic confusion (e.g. fear↔sadness, disgust↔anger).
Label Distribution Across Splits
Joy dominates (43 % of training labels), while disgust and neutral are severely underrepresented. This imbalance directly explains the low F1 on those classes.
